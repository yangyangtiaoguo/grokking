**兜底分层（用户要求）：**
- **L1 地板（已银行存款）**：M1+M2+M3 正式规模复测（多种子+误差棒）→ 即使所有判别失败，也是一篇完整回答 Zhao 开放局限的实证论文。
- **L2 中层**：k-vs-p 判别、靶向救援、家族拟合——任何方向的结果都可写。
- **L3 顶层**：p_star 机制 + 任务泛化——成了是 mechanism paper，不成不影响 L1/L2。

## 1. 设计原则（先导链教训，硬约束）

1. **曝光匹配**：边界测量必须步数 ∝ 2^n（n=12 用 240k），否则动力学读成热力学（P11b 教训，写进 M4 协议）。
2. **预算曲线伴随**：每个关键边界点至少 2 个预算档，分离 τ 发散与真稳态。
3. **判决规则冻结**：GROK=tail-mean A_unif>0.9；TRAP=A_hi>0.9 且 A_unif<0.5；CRUSH=A_hi<0.9 且 A_unif<0.5；PARTIAL=其余（P8 规则，正式阶段不变）。
4. **一次一变量**：换 n 时配方原封不动（v6 教训）。
5. **预注册先行**：对照曲线（家族候选）在实验前冻结（已有 theory_curves.json + p9_theory_boundary.json）；新候选 p_star 的预言斜率（n·ln2）在拟合前写下。

## 2. 里程碑与预算（单卡 RTX 5080，~95s/60k-run@n=10）

### M0 sanity（必须，~5 min）
3 runs：(α=0, wd=0.3) 期望 GROK；(α=2.5, wd=0.3) 期望 TRAP；(α=2.5, wd=0.3, k=1 靶向注入) 期望 GROK（验证注入通路）。任一不符 → 停下修 code。

### M1 边界正式测量（必须，~5.6h）
- **n=10 探针**（括号来自合并先导天花板，5 seeds/点）：α=2.0–2.6 各 1 个加密点（0.31/0.19/0.125/0.11/0.085/0.065）；新行 α=2.7（0.04/0.05/0.06）；右壁钉死 α=2.75（0.02/0.03/0.04）、α=2.9（0.03/0.04）、α=3.0（0.03/0.04, 3 seeds）；**新领土：低 α 高 wd 探区** α=1.0（0.7/1.0）、α=1.5（0.6/0.8/1.0）各 3 seeds——CRUSH 重叠区，E_c vs 2^(−α) 判别的关键区段（18% vs 50% 差异）。
- **n=12 曝光匹配**（240k 步，~6.3 min/run，3 seeds）：α∈{2.0, 2.25, 2.5, 2.75, 3.0} × 2 wd/行。
- **预算曲线**：边界点 (2.25, 0.125)、(2.5, 0.085)、(2.75, 0.03) × B∈{120k, 240k} × 3 seeds。
- 产出：Figure 1（热图+边界带 CI）、边界 vs 四候选+p_star 拟合。

### M2 救援电池（必须，~2h）
- **(a) k-vs-p 判别器**（新，机制核心）：batch∈{64,128,256}，总样本恒定 7.68M（steps 反比调整），k∈{0,1}，α=2.5/wd=0.3，5 seeds。**判据：k=1 在所有 batch 下都救回 → 每批覆盖底板（覆盖机制）；只有 p≈常数才救回 → 质量机制。**
- **(b) 靶向救援**：α∈{2.5, 3.0} × 注入∈{uniform, tail(长进位态), head(低 x 态)} × k=1，5 seeds + k=0 基线 3 seeds。**预言（§10.4.3）：tail 有效剂量 < uniform；head 无效。**
- **(c) m* vs 预算**：α=2.5 × B∈{15k, 30k} × k∈{0,1} × 3 seeds。
- 产出：Figure 3（剂量-响应 + 双判别器）。

### M3 动力学（必须，~3h）
- **τ(α) 断面**：wd=0.05，α∈{2.25, 2.5, 2.6, 2.75}，240k 步（T_max 同步），3 seeds，t_grok = 首次持续 A_unif>0.9。
- **α_c(B) 右移**：wd=0.3，α=2.25@{120k,240k}、α=2.5@{120k}（240k 已有 P7），3 seeds。
- 产出：Figure 4（τ 发散 + 预算交点）。

### M4 机制拟合（必须，CPU ~0）
- 合并全部边界点（先导+M1），bootstrap-over-seeds 误差棒，五候选（+新 p_star）单标度拟合 + 斜率检验；k-vs-p 与靶向结果整合进统一叙事。
- **预注册（拟合前写下）**：p_star(α)=瓶颈态概率，预言 ceiling 斜率 ≈ −n·ln2 = −6.93（n=10；实测 −5.17，待 M1 新点后重估）。

### M5 鲁棒性（应做，~2h）
- 宽度 d∈{32,128} × 边界格 (α=2.5, wd∈{0.05, 0.1}) × 3 seeds；
- lr∈{5e-4, 2e-3} × 2 边界格 × 3 seeds；
- batch=512（Zhao 方向）× (α=2.5, wd=0.3) × 3 seeds。
- 兜底逻辑：定量移动可接受（报告为 robustness），只要**结构**（两边界+垂直壁）存活。

### M6 任务泛化（可选，推迟决策，预算上限 ~10h）
Dyck-1 或模加 + 偏斜。M1–M4 落地后依剩余预算决定。

## 4. 成功判据

- M1：边界点 ≥12 个解析（先导 6 + 新 ≥6），bootstrap CI 不重叠地排除 ≥2 个候选 → C4 落定。
- M2(a)：batch 三档结果一致指向单一机制（k 或 p）→ 机制裁定。
- M2(b)：tail < uniform 有效剂量（预言方向）且 head 无效 → 瓶颈态覆盖机制确认。
- M3：α_c(B) 右移可测且方向一致 → 预算-相界统一框架成立。
- 论文级判定：C1+C2+C3 正式复现（L1 保底）+ C4/C5 至少一项判别成功 → A 会投稿就绪。

## 5. 已知风险与对策

| 风险 | 对策 |
|---|---|
| 低 α 高 wd 探区全被 CRUSH 吞掉（无 grok 通道） | 本身是发现（CRUSH 边界吞并 grok 通道 = 相图第三结构）；报告为边界拓扑 |
| k-vs-p 判别模糊（中间结果） | 两个方向都可解释，写进 mechanism 讨论；不阻塞 L1 |
| p_star 拟合不比 E_c 好 | 家族判别仍成立（进位链>指数>质量）；p_star 降为讨论 |
| 种子噪声再次抹平边界 | 5 seeds + bootstrap CI；必要时对最关键的 3 个点加到 9 seeds |
| 单卡时间超预算 | M5/M6 可裁；M1–M4 是不可裁核心 |
